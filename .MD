## 🎯 Tujuan Proyek
Bangun website untuk **Mumtaz MacBook Store** (bagian dari **Mumtaz Group**) — toko jual-beli unit Apple (MacBook, iMac, Mac Mini, iPad) baru & second, dengan 4 cabang di Jawa.

Tujuan utama website: **konversi/CTA** — pengunjung diarahkan untuk menghubungi toko (WhatsApp/telepon) atau mengunjungi cabang untuk membeli, menjual, atau tukar-tambah unit Apple. Setiap section harus punya jalur CTA yang jelas, bukan sekadar company profile pasif.

Website terdiri dari 3 bagian besar:
1. **Landing Page** (public, fokus konversi)
2. **Katalog Produk** (public, dinamis dari database)
3. **Admin Panel** (private, login, untuk CRUD produk)

---

## 🛠️ Tech Stack (rekomendasi — silakan sesuaikan sesuai environment yang tersedia)
- **Framework**: Next.js 15 (App Router) + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui sebagai basis komponen (kustomisasi total, jangan terlihat "default shadcn")
- **Animasi**: Framer Motion untuk micro-interaction (scroll reveal, hover, transisi halaman) — gunakan secukupnya, jangan berlebihan
- **Database**: Prisma ORM + SQLite untuk development (mudah upgrade ke PostgreSQL/Supabase saat production)
- **Auth admin**: NextAuth.js (Credentials provider) atau session-based auth sederhana dengan hashing password (bcrypt) — cukup 1 role admin, tidak perlu multi-role kompleks
- **Gambar produk**: simpan di `/public/uploads` untuk versi awal, dengan struktur yang mudah dipindah ke cloud storage (Cloudinary/Supabase Storage) nanti
- **Form/validasi**: Zod + React Hook Form
- Jika ada preferensi stack lain di environment ini, gunakan itu — yang penting arsitektur tetap: SSR/SSG untuk landing & katalog (SEO-friendly), route terproteksi untuk admin.

## 🖥️ 1. Landing Page — Struktur Section

1. **Navbar** — sticky, logo, menu (Beranda, Katalog, Tentang, Cabang, Kontak), tombol CTA menonjol ("Hubungi Kami" / ikon WhatsApp), berubah style saat scroll.
2. **Hero Section** — headline kuat (value proposition: trusted Apple reseller, garansi, 4 cabang), sub-headline, 2 CTA (utama: "Konsultasi via WhatsApp", sekunder: "Lihat Katalog"), visual produk premium (mockup MacBook/iMac).
3. **Trust Bar** — badge singkat: jumlah cabang, tahun berdiri, garansi, jumlah unit terjual, dsb (angka bisa placeholder, ditandai jelas untuk diisi user).
4. **Kategori Produk** — grid kategori (MacBook, iMac, Mac Mini, iPad) dengan toggle/badge "Baru" & "Second", link ke katalog dengan filter otomatis.
5. **Produk Unggulan** — 4-6 kartu produk (dari database, fallback dummy data), tiap kartu ada harga, kondisi, badge cabang, tombol "Chat Sekarang".
6. **Kenapa Pilih Mumtaz MacBook Store** — value props (unit bergaransi, cek fisik & fungsi, bisa tukar tambah, cicilan/pembayaran fleksibel, teknisi berpengalaman) dalam bentuk grid ikon + copy singkat.
7. **Proses Beli / Jual / Tukar Tambah** — step-by-step sederhana (misal 3-4 langkah) dengan CTA di akhir.
8. **Cabang Kami** — 4 cabang ditampilkan sebagai card (nama cabang, alamat, jam operasional, tombol "Rute" & "WhatsApp cabang"), idealnya dengan embed map atau ilustrasi peta Jawa.
9. **Testimoni** — carousel/grid testimoni pelanggan (rating, foto/inisial, komentar singkat).
10. **FAQ** — accordion, pertanyaan seputar garansi, cara beli online, cara jual unit, metode pembayaran.
11. **CTA Banner Penutup** — full-width, ajakan kuat + tombol WhatsApp besar sebelum footer.
12. **Footer** — logo, deskripsi singkat, link cepat, kontak semua cabang, sosial media, copyright.
13. **Floating WhatsApp Button** — persisten di semua halaman, muncul setelah scroll sedikit, dengan sedikit animasi pulse agar mengundang klik.

## 🛍️ 2. Katalog Produk (Public, Dinamis)

**Struktur data produk (schema database):**
- id, nama produk, kategori (MacBook / iMac / Mac Mini / iPad), model/varian (misal "MacBook Pro 14" M3 Pro"), kondisi (Baru / Second), grade kondisi second (opsional: Mulus/Good/Fair), tahun/spesifikasi (RAM, storage, chip), harga, stok tersedia (boolean/angka), cabang (bisa multi-cabang atau 1 cabang), deskripsi, garansi (durasi), foto (multi-gambar), status tampil (aktif/nonaktif), tanggal input.

**Fitur halaman katalog:**
- Grid produk responsif dengan lazy load / pagination
- Filter: kategori, kondisi (baru/second), range harga, cabang
- Search bar (nama/model produk)
- Sort: harga termurah/termahal, terbaru
- Halaman detail produk: galeri foto, spesifikasi lengkap, harga, badge kondisi & garansi, tombol CTA "Tanya via WhatsApp" (bisa prefill pesan WA dengan nama produk), info cabang tempat unit tersedia
- Empty state yang rapi jika filter tidak menemukan hasil

## 🔐 3. Admin Panel (Private, Login)

- Halaman login (`/admin/login`) — form email/username + password, terproteksi (redirect otomatis jika belum login, session-based)
- Dashboard admin (`/admin`) — ringkasan singkat (jumlah produk aktif, stok habis, dsb — opsional)
- CRUD Produk:
  - Tambah produk (form lengkap sesuai schema di atas, upload multi-gambar dengan preview)
  - Edit produk
  - Hapus produk (dengan konfirmasi)
  - Toggle status aktif/nonaktif (sembunyikan dari katalog tanpa hapus data)
  - Update stok cepat
- Tabel produk dengan search & filter di admin (memudahkan cari produk untuk diedit)
- Logout
- Buat 1 akun admin default saat seed database (username/password disebut jelas di README agar user bisa ganti nanti) — **jangan hardcode credential di kode produksi, gunakan environment variable / seed script**

## 🎨 Arahan Desain (kelas premium, setara $10.000)

- **Gaya visual**: minimalis premium ala Apple — banyak whitespace, tipografi besar & tegas, foto produk jadi hero visual, warna netral (putih/hitam/abu) dengan 1 warna aksen brand (tentukan warna aksen yang elegan, misalnya emas/navy — sesuaikan dengan identitas "Mumtaz").
- **Tipografi**: gunakan font modern & clean (contoh: Inter, Geist, atau Söhne-like), hierarki jelas antara heading besar dan body text.
- **Micro-interaction**: hover state halus di kartu produk & tombol, scroll-reveal animation ringan, transisi antar section yang smooth — jangan berlebihan sampai terasa "berat"/lambat.
- **Konsistensi komponen**: button, card, badge, input harus konsisten di seluruh halaman (landing, katalog, admin).
- **Fotografi produk**: karena ini bisnis fisik, siapkan style penempatan foto produk yang premium (background netral, shadow halus, rounded corner konsisten).
- **Dark mode** opsional tapi jadi nilai tambah jika sempat.
- **Mobile-first**: mayoritas trafik toko retail biasanya dari HP — pastikan pengalaman mobile benar-benar rapi, bukan sekadar responsive asal muat.

## 📣 Strategi CTA (fokus utama proyek ini)

- Setiap section besar di landing page harus punya minimal 1 CTA yang jelas (bukan cuma di akhir halaman).
- CTA utama: **WhatsApp** (paling sesuai kebiasaan pembeli Indonesia) — gunakan link `https://wa.me/[NOMOR]?text=[pesan%20prefill]` agar pesan sudah terisi otomatis sesuai konteks (misal produk yang dilihat).
- CTA sekunder: telepon langsung, dan "Kunjungi Cabang" (link ke Google Maps).
- Gunakan elemen kepercayaan (trust signal) di dekat CTA: garansi, testimoni, badge cabang resmi — ini menaikkan conversion rate.
- Floating WhatsApp button di semua halaman.
- Pertimbangkan elemen urgency yang jujur (bukan fake scarcity), misalnya "Stok terbatas per cabang" jika memang relevan dengan data stok asli.
